# VTB Bot

Бот для парсинга объявлений с VTB-Лизинг, проверки дублей через Google Sheets и публикации в MAX.

## Что делает

1. **Парсит** объявления с `vtb-leasing.ru/auto-market/sale/`
2. **Проверяет дубли** через Google Sheets (Apps Script)
3. **Фильтрует** по флагам: только с «Доступно в лизинг» + «В наличии», без «Требует ремонта»
4. **Раскладывает** по категориям: легковые, самосвалы, седельные тягачи
5. **Публикует** в группы MAX по расписанию
6. **Ведёт** учёт в админке («Опубликовано сегодня»)
